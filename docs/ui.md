# UI（@cuenu/ui）・PWA（@cuenu/web）

## 開発・ビルド

```bash
source ~/.nvm/nvm.sh; nvm use default
pnpm --filter @cuenu/ui test        # vitest + Testing Library
pnpm --filter @cuenu/ui typecheck
pnpm dev:web                        # http://localhost:5173 。/api は http://localhost:8787（wrangler dev）へプロキシ
pnpm --filter @cuenu/web build      # 出力: apps/web/dist（sw.js を含む）。server が静的アセットとして配信
pnpm --filter @cuenu/web preview    # http://localhost:4173 。Service Worker の動作確認用
```

- プロキシ先は環境変数 `CUENU_API_TARGET` で変更可。
- Service Worker は本番ビルドでのみ登録する（dev では登録しない）。

## テーマ

- 基本 7 色は要件 11 章の HEX（`src/theme/tokens.ts` と `styles.css` の `:root` のみに定義。テストで一致と散在なしを検証）。
- 派生トークン: `--cu-accent-hover --cu-accent-pressed --cu-focus-ring --cu-border-strong --cu-danger --cu-code-background --cu-hover-overlay --cu-selection`。
  - `--cu-border` は投稿間の薄い区切り線。入力欄・ボタンなど操作に不可欠な境界は `--cu-border-strong`（3:1 以上）。
- 切替: 設定 → テーマ（システムに合わせる／ライト／ダーク）。`localStorage['cuenu.theme']` に端末ごとに保存。`getThemeInitScript()` を `<head>` 先頭に埋め込み、初回描画前に `data-theme` と `color-scheme` を確定する。
- コントラスト（`test/theme.test.ts`）: 本文・リンク・AI ラベル・投稿ボタン文字・危険色は 4.5:1 以上、フォーカス・操作境界は 3:1 以上を確認。
  - ライトの `textSecondary` は要件の `#65776B`（background 上 4.45:1）から、同系色で少し濃い `#617366` に調整（2026-11-04 ユーザー承認）。background 上 4.72:1、surface 上 5.06:1。
- 選択・エラーは色だけでなく記号（⚠ ✓）・下線・枠・文言を併用。

## 画面構成（1 カラム）

- ヘッダー: Cuenu／同期状態（必要時のみ文字表示）／ホーム・検索・設定
- ホーム: 入力欄（起動直後に表示。タイムライン取得を待たない）→ タイムライン（区切り線、新しい順）
- スレッド: 親投稿 → 返信（古い順）→ 返信入力
- 検索: キーワード（オフライン可）＋日付範囲・投稿者・タグ／意味検索（オンライン＋ログイン時のみ。不可時は理由表示）
- 設定: 接続・同期／ログイン・ログアウト／テーマ／通知／AI 状態・タイムゾーン・日次上限／エクスポート・インポート
- ホームと検索は表示切替しても保持（下書き・検索条件・スクロール位置）

## PWA

- Service Worker（`apps/web/sw-template.js` からビルド時に `dist/sw.js` を生成）: アプリシェルを事前キャッシュしてオフライン起動。`/api/*` はキャッシュしない。IndexedDB には触れないため、更新で未送信データ・下書き・一時画像は消えない。新しい版は待機し、画面上部の「更新する」で切替。
- Web Push: 設定 → 通知 →「通知を有効にする」で権限要求 → 購読を `/api/push/subscriptions` に登録。通知タップで `/?memo=ID` を開く（既に開いていればその画面でスレッドを開く）。iPhone はホーム画面に追加した PWA のみ。
- ログイン: 同一オリジンの `/api/auth/login`。トークンは `localStorage['cuenu.session']`。ログイン前の投稿も同じ DB（`createIdbRepository({ serverUrl: location.origin })`）に保存し、ログイン後に同期する。ログアウトしても端末内のメモは消さない。

## 要検証

- iOS 実機: 起動時のキーボード自動表示（autoFocus は iOS では効かない可能性）、ホーム画面 PWA の Web Push、セーフエリア・回転。
- `sw.js` と `index.html` は長期キャッシュしないこと（server の配信ヘッダー）。
- 1 万件時のタイムライン・検索の描画性能。

- AI 投稿の参照元は本文下に表示しない（ユーザー指示）。要件 7 章の「元の文脈に戻れる」は「…」→「参照元のメモを開く」で満たす
- タッチ主体の端末（`hover: none` かつ `pointer: coarse`）ではショートカット案内を非表示
- 本文カラムは最大 640px（`--cu-max-width`、従来どおり）
- SNS 風レイアウト（2026-11-04 ユーザー指示）: 投稿の左に種別アイコンの丸（自分=ペン / 画像要約=画像 / AI=✦ をアクセント色）。アバターの代替であり人物アイコンではない（要件 11 章「アバターの強調をしない」の範囲内とユーザー判断）
