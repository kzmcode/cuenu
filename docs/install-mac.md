# Mac 版の導入・更新・アンインストール

対象: Apple Silicon の Mac（Intel は未対応・未検証）。Rust などの開発環境は不要。

先に PWA + サーバーを自分の Cloudflare アカウントへデプロイしておく（[README](../README.md#セルフデプロイpwa--サーバー)）。

## インストール

```bash
brew tap kzmcode/tap
brew trust kzmcode/tap   # Homebrew 7 以降は、公式以外の Tap を信頼済みにしないと読み込まない
brew install --cask cuenu
```

Tap リポジトリは `kzmcode/homebrew-tap`。

## 初回起動（署名・公証なし）

Cuenu は Apple Developer ID 署名・公証をしていない（ad-hoc 署名のみ）。Homebrew 経由でも Gatekeeper の確認は省略されない。

**以下は想定手順で、対象 macOS での動作は未検証。**

1. アプリケーションフォルダの Cuenu を開く。「開けません」「開発元を検証できません」等の警告が出たら「完了」/「キャンセル」で閉じる。
2. システム設定 → プライバシーとセキュリティ → 下部の「Cuenu は…ブロックされました」の横の **このまま開く** を押す（管理者パスワードを求められる場合がある）。
3. もう一度 Cuenu を開き、確認ダイアログで「開く」を選ぶ。

- 古い macOS では Finder で Control+クリック →「開く」でも許可できる場合がある。
- セキュリティ機構の無効化（`spctl --master-disable` 等）や、隔離属性の削除（`xattr -d com.apple.quarantine`）は**標準手順にしない**。自己責任で行う操作であり、本手順では推奨しない。
- 「壊れているため開けません」と表示される場合は、配布物の破損・ダウンロード途中の失敗の可能性がある。`brew reinstall --cask cuenu` を試し、解決しなければ Issue で報告する（SHA-256 は Releases の `.sha256` で確認できる）。

## 初期設定

1. 「サーバー URL」に自分のデプロイ先（例 `https://cuenu.<あなたのサブドメイン>.workers.dev`）を入力。
2. 「所有者パスワード」にサーバーの `OWNER_PASSWORD` を入力して「接続してログイン」。
3. 接続確認とログインに成功すると、端末トークンが Keychain に保存され、PWA と同じメモの同期が始まる。
4. 通知を使う場合は 設定 → 通知 →「通知を有効にする」（macOS の許可ダイアログで許可）。iPhone の通知とは別設定。
5. クイック入力は **⌃⌘M**（Control＋Command＋M）。設定 →「Mac: クイック入力」でキーを押して変更できる。

AI キー等のサーバー Secret を Mac に入力する必要はない。

## 使い方

- ショートカット → 入力 → ⌘Enter で保存して閉じる。Esc は下書きを残して閉じる。
- 通常ウィンドウを閉じても常駐し、ショートカットは使える。終了は ⌘Q かメニューバーのアイコン →「Cuenu を終了」。

## 更新

```bash
brew update
brew upgrade --cask cuenu
```

接続先・ログイン情報（Keychain）・ローカルのメモ・未送信の変更は更新後も保持される設計（更新時の保持は要検証）。更新後に初回起動と同様の許可操作が必要になる場合がある。サーバーと互換性がない場合は、起動時の接続確認で理由と更新手順（アプリ更新 or サーバー再デプロイ）が表示される。

## アンインストール

```bash
brew uninstall --cask cuenu
```

通常のアンインストールでは、メモ・未送信の変更・設定・Keychain のトークンは**削除されない**（再インストールで続きから使える）。

すべて削除する場合は [docs/recovery.md の「完全削除」](recovery.md#完全削除) を参照。未送信の変更がある場合は、先に同期するかエクスポートしてから行う。
